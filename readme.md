# ☆ MHS-CodeSnippets ☆

> "My digital cookbook for reusable logic."

Welcome to **MHS-CodeSnippets**! This repository serves as a personal library for the code blocks, algorithms, and logic patterns that I find myself rewriting constantly or experimenting with. The goal is to have a centralized location for these snippets, making it easier to reference and reuse them in future projects. 

Feel free to explore the collection, and if you find something useful, you're welcome to use it in your own projects. Just remember to follow any licensing terms provided with the snippets, and give credit where it's due.

## ☆ The Toolbox

Here is a breakdown of the languages, tools, and environments featured in this collection:

### Languages
* **C#** (General & Game Dev)
* **C++** (Performance & Systems)
* **Elixir** (Functional & Concurrency)
* **HTML / Web** (Front-End, Semantics & UI)
* **Java** (Software Engineering)
* **Lua** (Embedded & Game Scripting)

* **U#** (VRChat UdonSharp)

### Engines & Environments
* **Unity**
* **Unreal Engine**
* **Roblox Studio / LÖVE 2D**
* **VRChat**
* **Visual Studio 2022 / VS Code**

## ☆ Usage
Feel free to browse the language and category folders to find specific implementations. Most files include standard header documentation explaining the file's purpose, language, and date of creation.
