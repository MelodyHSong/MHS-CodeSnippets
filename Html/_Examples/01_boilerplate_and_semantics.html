Why Use Semantic HTML?

Published: September 3, 2026 by MelodyHSong

Rather than relying exclusively on generic <div> and <span> elements, semantic HTML introduces tags that carry explicit contextual meaning. Screen readers, search engines, and browser accessibility trees consume these landmarks to navigate web content efficiently.

"Good code is self-documenting; good markup is self-describing." — Front-End Design Principles
<section>

Key Semantic Landmarks

Each section represents a distinct thematic chunk of content, typically with its own heading:

  • <header>: Introductory content, mastheads, navigational groups.
  • <nav>: Major navigation links and menus.
  • <main>: Unique, central content of the document.
  • <article>: Independent, distributable content items.
  • <section>: Thematic grouping with heading hierarchy.
  • <aside>: Tangentially related content, sidebars, or callouts.
  • <footer>: Authorship, licensing, copyright, back-to-top links.

Pro-Tips & Notes

Always specify the document language in the root element:

<html lang="en">

Ensure every page has a descriptive <title> and responsive viewport meta tag for mobile devices.
